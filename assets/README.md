# 🎨 assets/ — The Archipelago's Attic

> *Generated sprites, painted backgrounds, ambient audio. Every image started as a prompt from the room's mood.*

Visual and audio assets for the ScummVM Prototype. Generated through [MMX](https://github.com/SuperInstance), [FLUX-2-max](https://github.com/SuperInstance), and the [tap-image-gen](https://github.com/SuperInstance/the-tap/tree/main/tap-image-gen) pipeline. Dark maritime, amber/copper, painterly — the aesthetic of a [fishing vessel rendered as adventure game](https://github.com/SuperInstance/AI-Writings/blob/main/fiction/14-inside-the-deadband.md).

## Subfolders

| Folder | Contents |
|--------|----------|
| [`rooms/`](./rooms/) | Background renders — bar rail, aft deck, engine room, galley, transitions |
| [`npcs/`](./npcs/) | Character sprites — Riker, Captain, Cook, Deckhand, Hermes |
| [`items/`](./items/) | Interactive items — chart, chess set, coffee, compass, key, life ring |
| [`ui/`](./ui/) | Interface elements — inventory bg, title screen, verb bar |
| [`map/`](./map/) | Vessel map — the spatial overview |
| [`effects/`](./effects/) | Animation frames — door opening, fade transitions |
| [`audio/`](./audio/) | Ambient audio, SFX, narration |
| [`objects/`](./objects/) | Additional scene objects |

## The Aesthetic

Every image carries the same base: dark maritime, amber/copper, painterly. Room mood (via [JEPA](https://github.com/SuperInstance/hermes-perception)) adjusts style modifiers. Phantom phrases from stories slip into prompts as whispers. See: [tap-image-gen design](https://github.com/SuperInstance/the-tap/tree/main/tap-image-gen) for the full pipeline.
